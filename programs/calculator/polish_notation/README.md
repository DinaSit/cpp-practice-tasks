### Polish Notation

Основная сложность при создании калькулятора заключается в определении порядка выполнения операций и построении дерева
разбора выражения. [*Дерево разбора выражения*](https://en.wikipedia.org/wiki/Binary_expression_tree) — корневое дерево,
вершинами которого являются операции, а дети вершин — подвыражения (операнды). В листьях дерева находятся числа
(константы).

Выражения, записанные в [польской нотации](https://en.wikipedia.org/wiki/Polish_notation), очень просты для разбора, так
как операции в ней уже записаны в нужном для вычисления порядке (в порядке pre-order обхода дерева).

*Примеры:*

```
"+ 3 4": читаем операцию + -> операция бинарная -> читаем первый операнд (3) и второй (4) -> получаем дерево:
  +
 / \
3   4
```

```
"+ 3 * 4 5": читаем операцию + -> операция бинарная -> читаем первый операнд (3) -> второй операнд — это результат
операции * -> читаем операнды операции * (4 и 5) -> получаем дерево:
  +
 / \
3   *
   / \
  4   5
```

---

#### Базовый алгоритм

Пусть имеется массив токенов, а текущая позиция в нём – `pos`. Построение дерева разбора осуществляется следующим образом:

1. Определяем тип текущей операции (токена). Сдвигаем `pos` на 1 элемент вправо.
2. Если операция не требует аргументов (константа), то возвращаем ее в качестве результата.
3. Если операция унарная, создаём узел дерева с данной операцией, рекурсивно строим поддерево для её единственного
   операнда, сохраняем результат в качестве ребенка узла, возвращаем сформированный узел.
4. Если операция бинарная, создаём узел дерева с данной операцией, рекурсивно строим поддеревья для первого и второго
   операндов, сохраняем их в качестве левого и второго ребенка соответственно, возвращаем сформированный узел.

Например, возведение в квадрат – унарная операция. Сначала извлекается токен операции, затем рекурсивно строится
поддерево для операнда (следующий токен). Полученный узел сохраняется в поле объекта класса `Square`, после чего
возвращается сформированный узел `Square`.

Аналогично, операция суммы – бинарная: сначала извлекается токен суммы, затем строится поддерево для первого операнда
(результат сохраняется в поле объекта `Sum`), после чего строится поддерево для второго операнда. В итоге возвращается
узел `Sum`.

*Пример:*

```
"+ sqr 3 5"
1. Начинаем построение дерева.
2. Токен '+' -> создаём узел типа Sum.
3. Рекурсивно строим первое подвыражение:
    3.1. Токен 'sqr' -> создаём узел типа Square.
    3.2. Рекурсивно строим операнд для Square:
         3.2.1. Токен '3' -> создаём узел Constant(3) и возвращаем его.
    3.3. Сохраняем полученный узел в поле операнда узла Square.
    3.4. Возвращаем узел Square.
4. Сохраняем полученный узел Square в первое поле узла Sum.
5. Рекурсивно строим второе подвыражение:
    5.1. Токен '5' -> создаём узел Constant(5) и возвращаем его.
6. Сохраняем полученный узел во второе поле узла Sum.
7. Возвращаем узел Sum.
```

В итоге получается следующее бинарное дерево:

```
    +
   / \
 sqr  5
  |
  3
```

Если выражение записано корректно, то после завершения рекурсивного построения дерево будет включать все токены, а значение `pos` станет равным длине массива токенов.

#### Детали реализации

Решение состоит из двух частей — токенизации и построения дерева разбора.

В файле `expressions.hpp` объявлены классы операций:

* `IExpression` — абстрактный класс для представления произвольной операции;
  * Содержит единственный публичный метод `int Calculate() const`, который вычисляет операнды и возвращает результат
      операции.
* `Constant` — наследник `IExpression`.
  * Имеет конструктор от `int`, сохраняющий значение константы в свое поле.
  * Реализует метод `Calculate` (просто возвращает сохраненное значение).
* `IUnaryOperation` — абстрактный класс, наследник `IExpression`, представляющий произвольную унарную операцию.
  * Имеет конструктор от `std::unique_ptr<IExpression>`, который сохраняет переданный указатель (операнд).
  * Имеет метод `int Operation(int operand) const`, который применяет операцию к вычисленному операнду.
  * Реализует метод `Calculate` путем вычисления операнда и применения к нему операции.
* `IBinaryOperation` — абстрактный класс, наследник `IExpression`, представляющий произвольную бинарную операцию
  * Имеет конструктор от двух `std::unique_ptr<IExpression>`, который сохраняются как операнды.
  * Имеет метод `int Operation(int lhs, int rhs) const`, который применяет операцию к вычисленным операндам.
  * Реализует метод `Calculate` путем вычисления операндов и применения к ним операции.
* Классы операций `Plus` (+), `Minus` (-), `Sum` (+), `Subtract` (-), `Multiply`(*), `Divide`(/), `Residual`(%),
`Minimum`(min), `Maximum`(max), `AbsoluteValue`(abs), `Square`(sqr), которые должны быть унаследованы от соответствующих
абстрактных классов (`IUnaryOperation` или `IBinaryOperation`) и реализовать соответствующий метод `Operation`.

Также реализована функция int CalculatePolishNotation(std::string_view input) которая выполняет следующие шаги:
1. Токенизирует входную строку.
2. Строит дерево разбора выражения.
3. Вычисляет и возвращает результат выражения.

Программа бросает исключения `UnknownSymbolError`, если в результате токенизации был получен неизвестный токен;
`WrongExpressionError`, если выражение составлено некорректно.

Гарантируется, что все промежуточные результаты помещаются в `int`.
