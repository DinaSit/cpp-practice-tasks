## Remove

**Концом последовательности называется элемент следующий за последним.**

Реализация шаблонной функции Remove, которая принимает последовательность (указатели на начало и конец) и значение value. Функция переупорядочивает элементы так, чтобы в последовательности не осталось элементов value, при этом порядок следования остальных элементов друг относительно друга должен остаться тем же. Функция возвращает указатель на конец полученной подпоследовательности.

Функция работает за линейное от размера последовательности время.

### Пример
```c++
int a[]{1, 2, 6, 4, 1, 1, 8, 0, 1};

Remove(a, a + 9, 1);  // возвращает a + 5 (a = [2, 6, 4, 8, 0, ?, ?, ?, ?])
// ? означает, что элемент может быть произвольным
```
