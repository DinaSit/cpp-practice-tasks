## IsSortedUntil

**Концом последовательности называется элемент следующий за последним.**

Реализация шаблонной функции Unique, которая принимает неубывающую последовательность (указатели на начало и конец), переупорядочивает элементы так, чтобы в начале последовательности шли уникальные элементы последовательности в порядке возрастания, и возвращает указатель на конец полученной подпоследовательности.

Функция работает за линейное от размера последовательности время.

### Пример
```c++
int a[]{1, 2, 2, 3, 3, 4, 5, 5, 6};

Unique(a, a + 9);  // возвращает a + 6 (a = [1, 2, 3, 4, 5, 6, ?, ?, ?])
// ? означает, что элемент может быть произвольным
```
