## IsSortedUntil

**Концом последовательности называется элемент следующий за последним.**

Реализуем шаблонную функцию IsSortedUntil, которая принимает два указателя: указатель на начало и конец последовательности. Функция ищет первый элемент с начала, который нарушает отсортированность последовательности по неубыванию, и возвращает указатель на него. Если последовательность отсортирована, то возвращается указатель на конец последовательности. Из сравнений можно использовать только операцию "меньше" `<`.

**Задача:** вернуть указатель на первый элемент, который нарушает неубывающую отсортированность на отрезке [first, last).
Если всё отсортировано — вернуть `last`.

### API
`template<class T> const T* IsSortedUntil(const T* first, const T* last);`

### Идея
Идём слева направо и сравниваем соседние элементы: если `*(i) < *(i-1)` — это первая “поломка”, возвращаем `i`.

### Сложность
`O(n)` по времени, `O(1)` по памяти.

### Краевые случаи
- пустой диапазон (`first == last`) → `last`
- один элемент → `last`
- повторы допустимы (неубывание)

### Пример
```c++
int a[]{1, 2, 2, 3, 3, 4, 2, 5, 6};
IsSortedUntil(a, a + 9);  // возвращает a + 6
```
