## IsSortedUntil

**Концом последовательности называется элемент следующий за последним.**

Реализация шаблонной функции IsSortedUntil, которая принимает два указателя: указатель на начало и конец последовательности. Функция ищет первый элемент с начала, который нарушает отсортированность последовательности по неубыванию, и возвращает указатель на него. Если последовательность отсортирована, то возвращается указатель на конец последовательности. Из сравнений можно использовать только операцию "меньше" `<`.

### Пример
```c++
int a[]{1, 2, 2, 3, 3, 4, 2, 5, 6};
IsSortedUntil(a, a + 9);  // возвращает a + 6
```
